Chapter Quest V4 - existing Cloudflare Worker update package
Target Worker name: chapter-quest-v4
This is a static-assets-only deployment. Do not paste HTML into worker.js.
Requires a computer/terminal with Node.js and Wrangler, authenticated to the correct Cloudflare account.
From this directory: npx wrangler deploy
Check the target Worker and account carefully before confirming any deploy.
Do not delete the existing Worker or clear browser storage.
Before deploying, back up the current browser's V4 data via the app's backup function.
Local IndexedDB PDFs are not included in JSON backups; retain the same browser/profile/device.
Manual approval UI is included; end-to-end server posting has not been verified.
