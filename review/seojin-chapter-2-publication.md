# 서진 Chapter 2 운영 게시

1. 열린 운영 탭의 부모 관리자 PIN 설정을 완료한다. 부모 화면의 **부모 계정 로그인 · 백업**에서 **로그인됨**을 확인한다.
2. 부모 관리자에서 기존 The Zack Files의 Chapter 2 초안을 연다. 초안이 로컬에 없으면 해당 챕터의 편집 화면에서 **AI 초안 JSON 가져오기**로 기존 `29-2-draft.json`을 선택한다. **원본 PDF/TXT 등록**에는 `29-2.pdf` 원본을 선택한다. 초안 JSON에는 AI 본문이 포함되지 않으므로 AI 본문 입력란에는 기존 검토 묶음의 `29-2-source-ocr.txt`를 사용한다. 기존 승인본이 로컬에 있으면 그대로 사용한다. 승인 기록이 없다면 현재 단일 챕터의 검토본이 승인 자료와 일치할 때만 **부모 승인 저장 · 서버 게시 별도**를 누른다.
3. 함께 제공된 READ-ONLY SQL에서 기존 후보와 11월 25일 일정을 확인한다. 제목이 비슷한 다른 책은 사용하지 않는다. 11월 19일 조회된 Leaving Again 후보는 승인 도서가 다르고 PDF 크기는 18,032,546바이트였다. 원본은 11,937,462바이트다. 후보의 크기는 선별 기준이며 파일 동일성은 실제 원본과 대조한다. 같은 원본이 확인되면 재사용한다. 등록이 없을 때만 **현재 챕터 원본을 서버에 등록**을 한 번 누르고 **서버 챕터·학생 목록 새로고침**에서 검증 완료를 확인한다.
4. **연결 요청 불러오기**를 눌러 활성 학생 목록을 불러온다. **서버 게시 대상 학생**에서 방금 검증한 서버 PDF를 선택하고 서진 한 명만 체크한다. **승인 자료 게시 · 학생 배정**을 누른다. 응답 유실 시 새 PDF나 승인 요청을 만들기 전에 DB 조회로 게시 여부를 확인한다.
5. **부모 직접 챕터 공개 → 공개 상태 새로고침**에서 서진의 Chapter 2 행을 찾는다. `2026-11-25`를 선택하고 **일정 저장**을 누른 다음 날짜가 저장됐는지 확인한다. 그 행의 **지금 공개**를 눌러 공개 플래그를 설정한다. 운영 공개 함수는 플래그와 서울 날짜를 함께 사용하므로 공개 시작은 `2026-11-25 00:00 Asia/Seoul` (`2026-11-24T15:00:00Z`)이다. 날짜에 오류가 있으면 공개 플래그를 설정하기 전에 중단한다.
6. 같은 SQL을 재실행한다. 정확한 PDF 후보, 연결된 승인 ID, 게시 활동, 전체 배정 1건과 서진 배정 1건, 예약 날짜·시간대·공개 플래그, Chapter 1 기준 행 보존을 확인한다. 별도 학생 세션에서 실제 조회하기 전까지는 학생 화면 결과를 확인한 것으로 표시하지 않는다.
7. 장애가 있으면 해당 Chapter 2 행에서 **비공개 전환**으로 공개 플래그를 끄고 재조회한다. 원본·승인·배정·수업 행은 유지한다. 등록 중 응답이 끊기면 새 항목을 만들기 전에 서버 PDF 목록과 검증 상태를 확인한다.

운영 API 경로는 `cq-v4-pdf-parent`의 `create_chapter → upload_url → signed PUT → finalize_upload`, 이어서 부모 인증을 사용하는 `cq_v4_register_approval_once → cq_v4_bind_verified_pdf → cq_v4_publish_approved`다. 게시 결과 확인에는 `cq_v4_publication_status`를 사용한다. 일정 RPC는 `cq_v4_parent_schedule_lesson(p_student_user_id,p_chapter_id,p_lesson_date)`, 공개 플래그 RPC는 `cq_v4_parent_set_lesson_release(p_student_user_id,p_chapter_id,p_release)`다.
