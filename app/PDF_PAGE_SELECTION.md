# 기존 PDF의 페이지 선택과 첫 학습 준비

사용자의 최신 지시는 **Chapter 1 범위 미정**입니다. 앞선 1~11쪽 응답은 철회되었으며 코드나 실제 자료에 적용하지 않습니다. 운영 데이터·계정·배포는 변경하지 않았습니다.

## 읽기 전용으로 확인한 원본

운영 저장소에는 `Chapter`라는 비공개 PDF가 있으며 29,306,963바이트이고 서버 PDF 검증 완료 상태입니다. 저장 메타데이터의 키는 eTag, size, mimetype, cacheControl, lastModified, contentLength, httpStatusCode뿐입니다. PDF 내부 제목·페이지 수·목차는 저장 메타데이터에 없습니다. 현재 연결 도구에는 부모 인증으로 비공개 파일 본문을 가져오는 기능이 없으므로 **실제 페이지 수·챕터 구성·Chapter 1 원문 여부는 미확인**입니다. 서버 파일을 읽기 위해 비밀키를 요청하거나 운영 함수를 배포하지 않았습니다.

## 부모 화면의 구현

1. 이미 내려받은 원본을 열거나, 부모가 권한을 가진 기존 서버 원본을 기존 불러오기 경로로 기기에 보관합니다. 같은 서버 원본을 다시 등록하려 하면 기존 연결을 재사용하고 재업로드하지 않습니다.
2. `페이지 수·목차 확인`은 PDF.js로 실제 페이지 수, PDF 내부 제목과 저장된 책갈피를 읽습니다. 목차가 없으면 없다고 표시하며 Chapter 1 경계를 추정하지 않습니다.
3. 원본 미리보기에서 이전/다음·쪽 이동으로 페이지를 보고 `현재 원본 쪽을 시작/끝으로 선택`합니다. 시작/끝은 기본 빈칸이며 **파일 첫 페이지=1쪽**입니다. 인쇄된 책 쪽 번호와 다를 수 있습니다.
4. `선택 범위 미리보기`는 그 페이지들만 별도 PDF로 만들고 선택 범위만 표시합니다. 범위를 바꾸면 확인이 취소됩니다. 잘못된 값과 표시 실패, 바뀐 원본/챕터는 등록할 수 없습니다.
5. 부모가 미리 본 범위를 확인한 경우에만 **이 기기에** 별도 학습 챕터를 준비합니다. 동일 범위를 다시 선택하면 기존 챕터와 검토 문제를 유지합니다. 원본 PDF, 기존 TXT와 이전 자료는 덮어쓰지 않습니다. 미확정 서버 원본에서는 문제 생성·게시를 진행할 수 없습니다.
6. 선택한 쪽의 텍스트만 새 학습 자료의 원문이 됩니다. 스캔 PDF에서 텍스트가 부족하면 해당 범위 원문을 별도로 준비해야 합니다. 새 문제·승인·학생 배정은 자동 생성하지 않습니다.
7. 서버 등록은 부모 권한으로 기존 비공개 원본을 서버 내부에서 읽고 선택 쪽만 새 파생 PDF로 추출합니다. 원본을 재업로드하거나 수정하지 않습니다. 서버 범위 기록의 원본·파생 해시와 실제 페이지 수를 보존하고 전용 승인 RPC가 그 파생 UUID에 원자적으로 연결합니다. 원본 전체로 바꿔 연결할 수 없습니다. 학생 다운로드는 게시·배정·현재 부모 연결과 파생 해시를 검사합니다. 이 보강에는 신규 범위 기록 테이블·RPC 2개·Edge 후보 2개의 별도 운영 적용 승인이 필요합니다. 현재는 개발 브랜치와 로컬 테스트에만 적용했습니다.

원본 키·해시·페이지 범위·원본 서버 UUID는 로컬 학습 챕터와 부모 JSON 스냅샷에 포함됩니다. JSON 백업만으로 PDF/TXT/음성 바이너리를 복원할 수는 없습니다. 기존 파일도 별도 보관해야 합니다. 원본 전체의 참고 텍스트는 최대 10쪽만 보이며 학습 원문으로 확정하지 않습니다. 길거나 스캔된 전체 책 때문에 범위 선택 전에 전체 텍스트 추출을 강제하지 않습니다.

## 검증과 제한

새 단위 검사는 원본 바이트 불변, 선택 페이지 순서/크기, 단일 마지막 쪽, 잘못된 범위와 비-PDF 차단을 검사합니다. 브라우저 검사는 생성한 4쪽짜리 원본의 책갈피/쪽 이동/직접 선택, 미확인·변경 범위 차단, 범위 텍스트만 준비, 원본/TXT 보존, 중복 방지, 재로딩과 파일 읽기 중 챕터 전환을 검사합니다.

전체 로컬 Supabase 테스트는 TXT, 단일 PDF, 기존 서버 PDF에서 선택 범위를 만드는 세 시나리오를 실행합니다. 마지막 시나리오의 2~3쪽은 **합성 테스트 파일의 범위**이며 실제 `Chapter` 범위가 아닙니다. 서버 원본 재업로드 방지, 범위 미정 게시 차단, 파생 PDF만 등록, 원본 서버 바이트 불변, 문제 승인·배정·학습·제출·피드백 및 두 학생 분리를 검사합니다. 성공 여부는 최신 PR 체크 결과로 판단합니다.

화면 크기·터치 검증은 실물 Galaxy와 실제 29.3MB 파일의 메모리·가독성 검증을 대체하지 않습니다. 실제 원본 본문을 확보하고 부모가 범위를 확인하기 전 실제 Chapter 1 등록·배정은 보류합니다.
