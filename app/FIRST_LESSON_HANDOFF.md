> 최신 사용자 확인: The Knight at Dawn / The Dark Woods, 기존 PDF 전체 11쪽 중 **파일 1–11쪽 전체** 사용. 표지·목차·삽화 포함, 원본 파일/UUID 그대로 재사용. 아래 미정·철회 표현은 이전 조사 기록이며 최신 지시는 `FIRST_LESSON_CONFIRMED.md`가 우선합니다. 실제 본문은 부모 확인 정보이고 개발자의 운영 본문 검증은 미실행입니다.

## 실제로 확인한 운영 상태

- 부모·학생 연결 1건이 존재합니다. 양쪽 Auth 사용자도 존재하고 부모는 이메일 인증된 관리자입니다. 그 부모가 검증 PDF를 소유합니다.
- 연결된 학생은 **익명 Auth 계정**이며 이메일·전화번호가 없습니다. 일반 이메일/비밀번호 로그인으로 기존 익명 계정에 들어갈 수 없습니다.
- 서버의 `cq_students`에서 이름이 정확히 `서우`인 행은 0건이며, `서우`라는 승인 초대 기록도 0건입니다. 이는 서우가 계정을 갖고 있지 않다는 증명이 아닙니다. 기존 연결 1건이 서우인지는 확인하지 못했습니다. 이름이나 기기 데모 학생명만으로 계정을 매칭하지 않습니다.
- 비공개 원본 저장소에 `Chapter` PDF가 실제 존재합니다. 크기 29,306,963바이트, MIME `application/pdf`, 서버 검증 완료, 소유 부모 관리자 확인, 게시 0건·배정 0건입니다.
- 이 파일의 본문·페이지 범위·스캔 여부와 실제 Chapter 1 여부는 아직 확인하지 못했습니다. 메타데이터 확인을 본문 검증으로 표시하지 않습니다. 합성 문항은 실제 교재에 게시하지 않습니다.

개인 계정 ID·이메일·인증 정보는 이 공개 저장소 문서에 기록하지 않습니다. 계정 생성·삭제·익명 계정 변환·재연결·자료 게시·학생 배정은 실행하지 않았습니다.

## 한 번에 실행하는 전체 학습 검증

`.github/workflows/validate.yml`은 무료 공개 Linux runner의 격리된 로컬 Supabase에서 `full_browser_test.py`를 TXT, 단일 PDF, 선택 범위 PDF 각각 실행합니다. 실제 사용자 파일이나 운영 계정은 사용하지 않습니다. 추가한 검사는 최신 PR 체크가 성공한 경우에만 완료로 판정합니다.

각 원본의 동일한 시나리오: 부모 로그인 → 합성 학생 초대/승인 → 원본 등록·화면 미리보기·원문 확인 → JSON 문제 초안 검토/승인 → 비공개 PDF 검증·연결·배정 → 학생 단어·독해·추론·영어 글쓰기·말하기 대본 → 새로고침과 실제 Auth 재로그인 후 모든 답안 복원 → 실제 MediaRecorder 녹음의 기기 저장 → 새로고침·재로그인 후 녹음 복원 → 실제 Storage 업로드·최종 제출 → 부모 결과/녹음 재생·피드백 공개 → 학생 피드백 확인.

부모 로그아웃/재로그인 후 동일한 승인 챕터를 두 번째 합성 학생에게 배정합니다. 두 답안·피드백이 분리되고 서로의 음성 링크를 발급할 수 없는지 검사합니다. 360/412/800/1280px에서 터치 선택·글쓰기·제출·녹음 버튼과 부모 결과 화면을 검사합니다. 가상 마이크와 화면 크기 검증은 실물 Galaxy 검사를 대체하지 않습니다.

실제 AI 모델 호출은 하지 않습니다. 무료 플랜/모델 사용 가능 여부를 검증하기 전 AI는 기본 차단이며, 검토한 JSON 초안 가져오기와 수동 입력 경로는 별도 AI API 비용이 없습니다.

## 코드 구현 완료, 실환경 검증 필요

PDF/TXT 원본 등록·미리보기·텍스트 추출, 기존 PDF 복원, 검토/승인/배정, 학생 학습·자동 저장·녹음·제출·피드백과 데이터 분리 구현은 기존 PR에 있습니다. 운영 후보 프런트엔드, 부모 원본/녹음 읽기 액션과 서버 범위 추출 액션, 학생 PDF 권한·해시 검사, 부모 읽기 RPC 및 신규 범위 기록·RPC 2개는 아직 배포/적용하지 않았습니다. 상세 적용·복구 범위는 `server-review/PDF_RANGE_APPROVAL.md`에 있습니다. 실제 운영 인증·자료·Galaxy에서의 실행 성공은 주장하지 않습니다.

Cloudflare는 기존 설정과 저장된 공식 무료 문서 검토 범위만 유지합니다. 실제 계정 플랜·현재 배포 ID·CPU 사용량은 미검증입니다. 추가 인증 코드를 발급하지 않습니다.

## 첫 학습 전 반드시 해결할 문제

1. 실제 Chapter 1 원문과 범위를 확인하고 문제·정답·단어·글쓰기/말하기 활동을 교재에 맞춰 검토해야 합니다.
2. 기존 익명 학생 계정이 서우의 계정인지와 원래 기기에 세션이 남아 있는지 확인해야 합니다. 익명 계정이라는 이유만으로 삭제하거나 다른 계정으로 대체하지 않습니다. 기존 UID를 보존하는 복구/연결 방안은 확인 후 별도 승인 대상입니다.
3. 승인된 배포와 실제 학생 배정이 필요합니다. 배포 전 직전 버전/설정과 복구 대상을 확보하고 변경 범위를 승인받습니다. 현재 운영의 게시·배정 0건 상태를 첫 학습 준비 완료로 표시하지 않습니다.
4. 실제 Galaxy에서 로그인·PDF 가독성·문제 선택·키보드·마이크 허용·최종 제출·피드백을 확인해야 합니다.
