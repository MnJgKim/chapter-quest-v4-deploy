# 운영 원본 미리보기 재점검 — 읽기 전용

현재 운영 `cq-v4-pdf-parent`는 v2이고 JWT 검증이 켜져 있습니다. 실제 배포 소스를 읽어 확인했으며 `download_url`과 `create_range` 액션은 없습니다. 개발 후보를 운영에 적용하지 않았으므로 부모 원본 미리보기 액션도 아직 운영에서 실행할 수 없습니다. 운영 PDF가 손상되었다거나 부모 권한이 잘못되었다는 증거는 아닙니다.

원본은 비공개 Storage에 있고 `Chapter`, 29,306,963바이트, 검증 상태입니다. 연결 도구는 SQL/함수 소스 조회를 제공하지만 Storage 파일 본문 다운로드 도구는 없습니다. 실행 환경에도 부모 인증 세션이나 비밀키 바인딩이 없습니다. SQL 메타데이터에 PDF 내부 제목·페이지 수·목차는 없습니다. 이 조건에서 본문을 확인하려고 학생 배정, 버킷 공개, 운영 함수 배포, 서비스 키 취득을 하지 않습니다.

개발 후보의 부모 미리보기는 Auth 사용자 확인 → 관리자 RPC → 부모/챕터 소유권 → 검증된 정확한 Storage 경로 → 120초 서명 링크 순서입니다. 학생/다른 부모는 거부됩니다. 브라우저도 같은 프로젝트·비공개 버킷·요청한 챕터 PDF 경로·서명·만료·크기·PDF 형식을 확인한 뒤 보관합니다. 이번 보강은 같은 프로젝트의 다른 PDF로 링크가 바뀌어도 다운로드 전 거부합니다. 원본 열기 자체는 등록·배정·덮어쓰기를 하지 않습니다.

실제 본문 확보는 부모가 Supabase Dashboard의 비공개 Storage에서 원본을 안전하게 내려받거나, 별도 승인 후 후보의 부모 미리보기 기능으로 확인하는 방법이 있습니다. 비밀번호·키·토큰을 채팅에 공유할 필요가 없습니다. 파일이 확보되어도 부모가 실제 Chapter 1을 보고 파일 페이지의 시작/끝을 확정하기 전 등록·배정은 보류합니다. 1~11쪽 지정은 철회된 상태입니다.

현재 자동 검증은 합성 PDF/사용자 기반입니다. 범위 원문만 생성 요청에 전달되는지와 부모 검토 전 미승인 상태를 검사하며, 실제 AI 대신 로컬 합성 응답을 사용합니다. 실제 교재 기반 문제 품질이나 운영 AI 호출 성공으로 표시하지 않습니다.
