# 세션 확인 화면 운영 적용 전 검토

## 후보 변경
기존 세션 확인 버튼 → 서버 신원 확인 → 기존 부모 연결 확인 → 기존 학생 RPC로 배정 목록 조회. 인증·연결·승인/배정 조회 결과를 각각 표시한다. 배정 0건으로 미승인이나 계정 삭제를 추정하지 않는다. 세션 기록을 삭제하거나 갱신하지 않는다. 이번 수정은 UI·안내·합성 검사이며 DB/Edge 변경은 추가하지 않는다.

## 실환경 확인 순서
1. 동일 태블릿·브라우저·프로필을 보존한다. 현재 운영에는 후보 버튼이 아직 없다.
2. 배포 승인과 적용 후 학생 서버 학습에서 기존 계정 확인 버튼을 한 번 누른다.
3. 인증과 부모 연결이 확인되면 계정 확인번호를 부모 화면과 대조한다. 0건이면 자료 게시·배정 여부는 부모가 확인한다. 누락/만료/오류이면 가입이나 저장소 초기화 없이 중단한다.
4. 승인된 자료가 실제 배정된 후 원문 PDF 1–11쪽, 단어, 내용 이해·추론, 글쓰기를 진행한다. 잠깐 나갔다 같은 계정으로 돌아와 임시 답안을 확인한다. 녹음·재생·최종 제출·부모 피드백 공개·학생 확인까지 한 번 진행한다. 이 단계의 답안/녹음/제출/피드백은 운영 데이터 쓰기이므로 별도 사전 승인이 필요하다.

## 위험과 한계
이 후보는 유효한 기존 SDK localStorage 세션만 지원한다. 만료·다른 브라우저·다른 저장 방식의 익명 계정 복구를 보장하지 않는다. 부모 연결 확인은 같은 UID의 enrollment 존재 확인이며 실제 인물 확인은 부모 대조가 필요하다. 접근 토큰 만료 시 중단하고 자동 갱신하지 않는다. RLS/서버 RPC가 최종 접근 권한을 결정한다.

PR 전체를 배포하면 세션 화면 외 기존 PR의 학습·PDF·부모 화면 변경도 함께 포함된다. 따라서 이번 UI 변경만으로 PR 전체의 운영 적용 안전성을 확정하지 않는다. SQL·Edge·자료 등록·배정·계정 수정은 프런트 배포 승인에 포함시키지 않는다.

## 백업 및 복구
코드 이력과 기존 원본은 보존한다. 실제 적용 전 기존 Cloudflare 배포 버전 ID·설정 및 되돌리기 접근 권한을 확보해야 한다. 실패하면 기존 버전으로 전환하고 후보 사용을 중단한다. 프런트 되돌리기는 이미 기록된 학습 데이터를 되돌리지 않으므로 운영 쓰기는 별도 승인한다. 브라우저 사이트 데이터 삭제는 복구 방법으로 사용하지 않는다.

현재 운영 버전 복구 권한·실기기 세션은 미검증이다. 배포 가능한 범위, 기존 버전 백업과 실행 권한이 구체적으로 확보된 뒤 최종 배포 승인을 요청한다. 이 문서는 운영 배포나 운영 데이터 변경을 승인한 기록이 아니다.
